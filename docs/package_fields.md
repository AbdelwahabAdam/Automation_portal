# Package fields — what the order form asks for each package

Generated from `PACKAGE_PROFILES` in `backend/app/modules/form_engine/options.py` against the live
catalogue. Do not edit by hand — change the profiles, then regenerate:

```sh
cd backend && python ../docs/gen_package_doc.py packages.tsv > ../docs/package_fields.md
```

`packages.tsv` is the live catalogue; the generator's docstring has the command that makes it.

Every package also has **الكمية (عدد الباقات)**, and a product sold without a fixed price has its
price and invoice text. **سعر الكتابة** appears wherever **الكتابة المطلوبة** does.

A package's name decides its profile: the first one whose words it carries. A package no profile
matches keeps every field, exactly as before profiles existed.
